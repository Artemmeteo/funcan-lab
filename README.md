# Функциональный анализ - кейсы 4 и 6

Код и отчёты по двум кейсам:
- **Кейс 4** - регрессия по функциональным данным через линейные функционалы;
- **Кейс 6** - метрические методы регрессии (Надарая-Ватсон, LOWESS).

## Структура

```
code/
  case4/                 # Кейс 4 (модули + главный скрипт)
    quadrature.py        #   численное интегрирование в L2
    data.py              #   синтетические функциональные данные
    functionals.py       #   системы функционалов и матрица признаков
    model.py             #   МНК, ridge, метрики, весовая функция
    plotting.py          #   настройка matplotlib и сохранение фигур/таблиц
    run.py               #   <- запуск: все эксперименты
  case6/                 # Кейс 6 (модули + главный скрипт)
    kernels.py           #   ядра
    metrics.py           #   метрика (расстояние) и MAE/RMSE/R2
    nadaraya_watson.py   #   НВ: фикс./перем. окно, LOO
    lowess.py            #   робастное перевзвешивание
    datasets.py          #   реальные датасеты (Diabetes, California)
    plotting.py
    run.py               #   <- запуск: все эксперименты
report/
  Кейс_4_отчёт.tex / .pdf
  Кейс_6_отчёт.tex / .pdf
  figures/               # графики (PDF) и таблицы (LaTeX) - генерируются из code/
  fonts/                 # шрифт CMU Serif
  build.ps1              # пересборка обоих PDF
tools/
  tectonic.exe           # LaTeX-движок (XeTeX)
```
